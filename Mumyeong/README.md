# 무명 (Mumyeong) — STS2 캐릭터 모드 (베타 v0.1.0)

한 번 죽었다 깨어난 이름 없는 자 「무명」. 런을 시작하면 저승의 **황천 영사실**에서 자신의 마지막 1초를 고르고,
그 선택에 가장 크게 공명한 위인 한 명의 코어를 받아 함께 싸운다. 영혼과의 관계는 런 동안
**빙의 → 동기화 → 집중 → 강림**으로 깊어진다.

- 설계 기준 문서: 저장소의 `docs/mumyeong-spec.md` (결정 기록: `docs/soul-character-design.md`)
- 구조는 같은 저장소의 엔시페르(`MagicSwordsman/`)와 같다(Alchyr ModTemplate-StS2 + BaseLib).

## 설치 A — 바로 설치 (빌드 없이)

1. 저장소의 `releases/Mumyeong-v0.1.0-beta.zip`을 받는다.
2. 압축을 풀면 나오는 `Mumyeong` 폴더(`Mumyeong.dll`, `Mumyeong.pck`, `Mumyeong.json`)를 게임 폴더의 `mods/` 안에 넣는다.
   예: `Steam/steamapps/common/Slay the Spire 2/mods/Mumyeong/`
3. BaseLib 3.4.7 이상이 설치되어 있어야 한다(창작마당 구독 등).
4. 게임을 "Play with Mods"로 실행하고 캐릭터 선택에서 **무명**을 고른다.

`.pck`는 Godot 에디터 대신 `BSchneppe.StS2.PckPacker`(템플릿 csproj에 주석으로 들어 있던 도구)로 만들었다.
글자가 안 보이거나 그림이 깨지면 아래 B 방법(MegaDot으로 `dotnet publish`)으로 다시 만들면 된다.

## 설치 B — PC에서 빌드

이 저장소에는 빌드된 `.dll`·`.pck`가 들어 있지 않다. 게임 파일(`sts2.dll`)이 있는 PC에서 한 번 빌드하면 게임
`mods` 폴더에 설치된다. 엔시페르와 같은 방법이다.

### 준비물
- **.NET SDK 9.0 이상**
- **MegaDot 4.5.1** (megadot.megacrit.com) — 게임은 4.5.1보다 새 버전으로 만든 `.pck`를 읽지 못한다
- **BaseLib 3.4.7 이상** — 게임에 설치되어 있어야 한다(Steam 창작마당 구독 또는 GitHub 릴리스)
- Slay the Spire 2 (Steam)

### 처음 한 번
1. 이 폴더(`Mumyeong/`)의 `Directory.Build.props.example`을 같은 폴더에 `Directory.Build.props`로 복사한다
   (git에 올라가지 않는다).
2. 그 안의 `<GodotPath>`를 PC의 MegaDot 실행 파일 경로로 바꾼다.
3. 게임이 Steam 기본 위치에 없으면 `<Sts2Path>` 줄의 주석을 풀고 게임 폴더 경로를 넣는다.

### 빌드
이 폴더(`Mumyeong/`)에서:

| 상황 | 명령 | 하는 일 |
|---|---|---|
| 처음, 또는 텍스트·이미지를 바꿨을 때 | `dotnet publish` | `.dll` + `.pck` + `.json`을 게임 `mods/Mumyeong/`에 복사 |
| 코드만 바꿨을 때 | `dotnet build` | `.dll`만 다시 복사 |

그다음 게임을 "Play with Mods"로 실행하고 캐릭터 선택에서 **무명**을 고른다.

텍스트를 고칠 때는 `tools/` 안의 데이터(`loc_cards.py`, `loc_scenes.py`, `build_loc.py`)를 고치고
`python3 tools/build_loc.py`로 `Mumyeong/localization/`을 다시 만든다. 임시 그림은 `python3 tools/gen_art.py`.

## 들어 있는 것 (베타)

### 캐릭터
- HP 70, 골드 99, 에너지 3. 시작 덱: 타격 ×4, 수비 ×4 + 영사실에서 온 위인의 시작 카드 2장.
- 시작 유물 **코어**: 계약한 위인·계약 유형·숙련·단계를 저장한다. 카드 보상·상점·변화·전투 중 생성 카드에는
  공용 카드와 계약한 위인의 카드만 나온다. 툴팁에 다음 단계까지의 진행이 보인다.

### 황천 영사실 (런 시작 이벤트)
니오우 이벤트가 끝나면 열린다. 시드로 뽑힌 위인 3명의 그림자(한 키워드만 보임)와 장면 1개(베타 24개) →
컷 3개(시선·행동·유언)에서 하나씩 고른다 → 공명이 가장 큰 위인이 스크린 속으로 걸어 들어온다 →
내 3컷과 그 위인의 실제 마지막 행적을 나란히 공개 → 계약.
- 공명 3/3 = **공명 계약**: 동기화·집중에 필요한 숙련이 줄어든다(25→15, 70→55).
- 그 외 = **한 계약**: 전투를 힘 1로 시작하지만, 위인 카드가 아닌 카드를 쓰면 한이 쌓이고 5가 되면 체력 4를 잃는다.

### 단계
| 단계 | 조건 | 보상 |
|---|---|---|
| 동기화 | 2막부터, 위인 카드 사용 누적 25 (공명 15) | 위인 카드 3장 중 1장 |
| 집중 | 3막부터, 누적 70 (공명 55) | 카드 1장 제거 또는 2장 강화 |
| 강림 | 3막, 집중 이후 위인별 과제 달성 | 위인 전용 유물 |

단계 상승(「영사실의 다음 릴」)은 조건을 채운 뒤 막이 바뀔 때, ? 이벤트를 마칠 때, 또는 휴식처의
「필름을 돌린다」(휴식 1회 사용)로 열린다.

### 위인 6명 × 카드 20장 + 공용 6장 = 126장
| 위인 | 방향 | 고유 수치 | 전용 유물 |
|---|---|---|---|
| 관우 | 활력을 쌓아 큰 한 방 | 활력 | 청룡언월도 |
| 잔 다르크 | 매 턴 방어도, 신념을 공격으로 | 신념 | 오를레앙의 깃발 |
| 레오니다스 | 방어도 유지, 반격 | 방진·반격 | 스파르타의 방패 |
| 칭기즈 칸 | 광역·다단, 처치 시 가속 | 기마 군단 | 대칸의 인장 |
| 이순신 | 턴 종료 포격, 다음 턴 준비 | 포격 | 거북선 |
| 나폴레옹 | 에너지·카드 운용, 포병 | 포병대 | 황제의 관 |

## 검증 상태 (중요)
- 사용자가 올린 게임 파일(실제 `sts2.dll` / `0Harmony.dll` / `GodotSharp.dll`)과 BaseLib 3.4.7로 **컴파일 성공**(오류 0, 경고 0),
  현지화 분석기 통과, 텍스트 키 대조(클래스 ↔ 현지화) 통과.
- **게임 안에서 실행해 보지는 못했다.** 실행 중 문제가 생기면 게임 로그(`godot.log`)의 `[Mumyeong]` 줄을 알려 주세요.
- 게임에서 확인해야 할 것:
  - 영사실·단계 이벤트가 강제로 열리는 타이밍(멀티플레이 포함), 이벤트 도중 저장 후 불러오기
  - 휴식처 「필름을 돌린다」와 카드 고르기 화면
  - 한 계약의 체력 손실, 강림 과제 판정
  - 밸런스 전반(숙련 기준, 카드 수치)

## 아직 없는 것
- 그림: 카드는 위인별 문양(임시), 유물·파워 아이콘도 임시 문양. 캐릭터 몸·선택 화면은 BaseLib 기본 모습.
- 캐릭터 선택 화면의 설명 버튼과 전환 애니메이션(치이카와 모드 방식) — BaseLib에
  `CustomCharacterSelectTransitionPath`가 있어 전환 장면은 연결할 수 있다. 다음 버전 예정.
- 위인당 50장 목표 중 20장, 장면 24개(계속 추가 예정).
