# 무협 캐릭터 — 기본 스펙과 카드 획득 구조

## 카드 획득 구조 (확정)
- **일반 전투 보상**: 이 캐릭터의 문파 공용 카드(여러 문파가 함께 쓰는 카드. 다른 캐릭터와 공유하는 무색 카드가 아님)와, 각 문파의 **최하위(★) 카드**만 등장한다.
- **문파의 진짜 카드(★★ 이상)**: **비급서로만** 얻는다.
- 비급서로 고른 문파 쪽으로 보상 확률을 쏠리게 할지: **미정**.

## 영약 흡수 이벤트 (방향 확정, 수치는 초안)
영약(내공 최대치를 올리는 아이템)을 얻으면 바로 강해지는 대신 고유 이벤트가 뜬다. 원작에서 영약의 기운을 다 담지 못하고 일부가 흩어지며, 무리하면 주화입마가 온다는 설정을 옮긴 것. 구현은 BaseLib의 `CustomEventModel`로 가능 (소스에서 클래스 존재 확인).

| 선택지 | 결과 |
|---|---|
| 안전하게 흡수 | 영약 효과의 일부만 내공 최대치로 저장. 실패 없음 |
| 전부 흡수 (위험) | 성공 시 전부 저장. 실패 시 주화입마 |

**주화입마 페널티** (하나 무작위, 또는 영약 등급이 높을수록 센 것): 내공 최대치 -1 / 저주 카드 `주화입마` 획득 / 최대 체력 감소.

**수치 제약**: 최대치는 1에서 시작해 상한 10이라 런 전체에서 오를 수 있는 양이 9칸뿐이다. "일부만 흡수"가 성립하려면 영약 하나가 최소 2칸은 줘야 한다. 초안:

| 영약 | 안전 | 전부 | 실패 확률 |
|---|---|---|---|
| 오백년하수오 | +1 | +2 | 10% |
| 천년하수오 | +1 | +3 | 25% |
| 만년하수오 | +2 | +4 | 40% |

- 상한 10을 넘긴 분량은 소멸.
- 선택 사항: 실패 확률을 고정값 대신 "현재 그릇(최대치) 대비 영약 세기"로 정하기 (세계관 문서의 그릇 제한 규칙). 처음엔 고정 확률로 시작 권장.

## 경지 연출 (채택)
내공 최대치 1~10에 경지 이름(삼류 → 생사경 8단계, `wuxia-worldbuilding-research.docx` 7장)을 붙여, 그릇이 커질수록 경지가 오르는 것을 보여준다. 10칸과 8단계를 어떻게 대응시킬지는 미정.

## 내공이 전투 후 유지되는가 (미정)
- **A. 유지 + 휴식처에서 회복**: 전투 사이 자원 관리가 생긴다. 휴식처에 "운기조식" 선택지를 추가해 내공을 채운다 (Wanderer가 휴식처에 Misogi 선택지를 추가한 전례 있음). 대신 휴식처에서 체력 회복과 경쟁한다.
- **B. 전투마다 초기화**: 단순하고 밸런스 잡기 쉽다. 전투 시작 시 내공을 0으로 둘지 최대치로 채울지 추가로 정해야 한다.
