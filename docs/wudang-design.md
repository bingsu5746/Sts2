# 무협 캐릭터 — 무당파 MVP 설계 확정 사항

> `design-memory.md`(최초 메모리 임포트) 이후, 이 세션에서 추가로 확정/변경된 내용만 다룬다.
> 근거 자료: `wudang-research.docx`(무당파 실제 무공 리서치), `wanderer-mod-analysis.md` / `watcher-reference-notes.md`(STS2 스탠스 구현 패턴).

## 확정된 것

### MVP 문파
10개 문파(소림사/무당파/화산파/종남파/사천당가/제갈세가/남궁세가/하북팽가/천마신교/북해빙궁) 중 **무당파**를 첫 구현 대상으로 확정. 내공 시스템의 "본가"라 캐릭터 핵심 자원과 정체성이 자연스럽게 맞물림.

### 내공(핵심 자원) 규칙
- **런 시작 시 최대치 = 1**
- 유물/영약 등으로 런 진행하며 **최대치가 점점 성장**
- **상한선(궁극 캡) = 10** — 더 늘어나지 않는 한계
- 현재 내공은 자동 회복 없음. 전투 중/후 모두 자연 회복 안 됨. 회복 수단은 운기조식류 카드로만.
- 최대치 성장분은 **유물/파워 모델의 프로퍼티에 저장**한다 (정적 Dictionary 금지 — Wanderer 분석에서 확인된 실패 사례: static Dictionary에 저장한 상태는 세이브에 안 남아서 전투 재개 시 날아감. 유물 프로퍼티는 세이브 대상이라 안전).

### 보법 "미니 스탠스" 메커니즘
Watcher/Wanderer 실제 구현 패턴(§ `watcher-reference-notes.md`, `wanderer-mod-analysis.md`)을 참고해 아래로 확정:

- **파워 1개짜리 상태**: `대기(待機)` — 보법 계열 카드(구궁보 등 아무 보법이나)를 내면 1스택 진입
- **효과**: 다음 카드 1장을 낼 때 발동 후 자동 소멸. 발동 효과는 "내공 소모 -1(최소 0)" — 사량발천근(적은 힘으로 큰 효과) 컨셉 반영
- **구현 패턴**: Watcher의 Divinity 스탠스처럼 "진입 시 상태 부여 + 특정 시점(다음 카드 재생 직후)에 자동 퇴장" 조합. 계열별 매칭(구궁보→구궁신행검 식 태그 시스템)은 **기각** — 너무 복잡하다는 피드백 반영, 보법 종류 상관없이 전부 동일 효과로 통일
- 스탠스가 1종류뿐이라 지금은 `IStancePower` 같은 마커 인터페이스 불필요. 나중에 보법 상태가 여러 종류로 늘어나면 그때 도입 검토

## 아직 안 정한 것 (열린 질문)
- **시작덱 10장 구성** — 무당장권×4 / 구궁보×4 / 운기조식×1 / 소청검법×1 초안까지는 나왔으나 보류 상태. 재논의 필요
- **비급서 획득 방식** — 3택1(방식2)과 숙련승급(방식3) 혼용 방향만 잡음, 세부 미정
- **Common/Uncommon/Rare 카드 목록** — 완전 미정. `wudang-research.docx`의 소모값 표를 그대로 가져다 쓸 수 있는 상태
- 데미지 공식 후보: 조사표의 "파괴력" 스탯(0~10) × 3 = 실제 데미지 (무당장권 파괴력2→6이 리젠트 기본공격과 일치해서 도출한 값, 검증 필요)
