> 2026-10-01 초안. 전부 **제안 단계** — 이름·수치·희귀도 모두 조정 가능.
> 분포는 STS2 바닐라 카드 풀(sts2.dll v0.107.1 검증)을 따라감: 아이언클래드 Basic 3 / Common 20 / Uncommon 36 / Rare 26 / Ancient 2.
> 레인저: **Basic 5 / Common 20 / Uncommon 36 / Rare 27 / Ancient 2 = 90**
> 타입: 공격 38 / 스킬 35 / 파워 17 (아이언클래드는 37 / 30 / 20)

## 표기 규칙
- **원 X / 근 Y** — 화살이 충분하면 원거리 효과 X, 부족하면 근접 효과 Y
- **화살 N** — 원거리 효과에 필요한(소모되는) 화살 수. 표기 없으면 화살 1. 화살이 부족하면 있는 만큼 원거리로 쏘고 모자란 발수만 근접 (확정)
- **깨짐** — 동상 상태의 적에게 화상을 걸면 결합해서 생기는 신규 상태: 취약 + 약화 + 추가 피해 (수치 미정). 순서 무관, 결합량 = 작은 스택 수, 나머지 스택은 남음. 동상 단독 = 약화와 동일
- **근접 전용 / 원거리 전용** — 한쪽 효과만 있는 카드
- **[시위]** — 1회 보존, 당겨 둔 뒤 쏘면 피해 +50%·속성 효과 2배
- 축 태그: 🏹속사 / ⚔쌍검 / 🔥속성 / 🎯저격 / 🍃곡예 / ·공용
- 수치 기준: 타격 6·수비 5 (바닐라 검증), 원거리 우위 X=+2 → 기본 원 7 / 근 5

## 설계 메모
- **화살 경제**: 회수 수단 — Basic 1, Common 4, Uncommon 8, Rare 5, 파워 4. 쌍검 축은 의도적으로 회수와 거리를 둠
- **바닐라 비교**: TwinStrike(아이언클래드 Common) = 1코 5×2 (sts2.dll 검증) → 연사를 원 6×2 / 근 5×2로 맞춤. 나머지 카드도 같은 방식으로 바닐라 대응 카드와 대조 예정
- 강화 수치는 다음 단계에서 일괄 설계
