## 0. 공통 규칙

### 0.1 표기
| 표기 | 뜻 |
|---|---|
| **L** | 그 마검의 강화 단계(0~5). 카드 설명에는 현재 단계가 반영된 숫자만 보인다(`WithLevelVar` 등) |
| `+1/L` | 단계마다 +1 (0단계 값 + L) |
| `+⌊L/2⌋` | 2단계·4단계에서 1씩 (0,0,1,1,2,2) |
| `3단계부터 X` | 문턱형. 3단계 이상에서 X로 바뀜 |
| 공용 카드 `6 (9)` | 기본 6, 휴식처 일반 강화 후 9 |
| 대상 | 적1 = `TargetType.AnyEnemy` / 전체 = `AllEnemies` / 무작위 = `RandomEnemy` / 자신 = `Self` (게임 열거형에서 확인) |
| 희귀도 | `CardRarity.Basic`(검을 얻을 때 지급, 보상·상점에 안 나옴) / `Common` / `Uncommon` / `Rare` |

### 0.2 단계당 상승 공식 (마검 카드 공통)
| 카드 성격 | 단계당 | 5단계 누적 | 원본 강화 1회와 비교 |
|---|---|---|---|
| 비용 0~1 단일 공격 | 피해 +1 | +5 | StrikeIronclad +3, Headbutt +3 |
| 비용 2 공격 | 피해 +2 | +10 | Predator +5 |
| 비용 3 공격 | 피해 +3 | +15 | Bludgeon +10 |
| 여러 번 때리기 | 타격당 +⌊L/2⌋ | 타격당 +2 | TwinStrike 타격당 +2 |
| 비용 0~1 방어도 | +1 | +5 | DefendIronclad +3 |
| 비용 2 방어도 | +2 | +10 | BloodWall +4 |
| 파워·특수 수치 | +⌊L/2⌋ 또는 문턱형(비용 감소 등) | — | Inflame +1 |
| **그람 카드(예외)** | 위 값의 절반: 비용 0~1 공격 +⌊L/2⌋, 비용 2 공격 +1/L, 다단은 4단계부터 타격당 +1 | — | 현재 검 효과 +L이 이미 모든 공격을 올리므로 이중 상승을 줄임 |

- 5단계 마검 카드 1장 ≈ 원본 강화 1.5~2회. 휴식처 1회 = 그 검 카드 3~5장 동시 상승 + 현재 검 효과 상승 → 일반 강화 1회보다 약간 높게(도박·박살 위험과 휴식 포기의 대가).
- 그람 카드도 "그 검의 카드 전부가 조금씩 강해짐"[확정 §4]을 지키도록 절반이라도 반드시 오른다(설계안 B는 그람 카드를 거의 올리지 않아 이 조항과 어긋날 여지가 있었음).

### 0.3 용어·키워드
| 용어 | 뜻 |
|---|---|
| 소환 | 그 검의 카드를 전투에서 처음 쓸 때 만검총에서 나옴(검마다 전투당 1회). 전투 첫 소환에만 만검총 효과(방어도 3 + 카드 1장) [확정] |
| 나온 검 수 | 이번 전투에 주변에 떠 있는 검 수 = `SwordCombatState.Present` 개수(소환된 검 + 스스로 나온 오니마루). 간장·막야는 각각 1. 봉인된 쿠사나기는 빠짐 |
| 전환 | 현재 검이 다른 검으로 바뀌는 순간(없음 → 검 포함). 같은 검 카드를 연달아 쓰는 것은 전환이 아님 |
| 【연속】 | 이 카드를 쓰기 직전 현재 검이 이미 이 카드의 검이면 발동 |
| 【짝】 | 간장·막야 전용. 쓰기 직전 현재 검이 반대쪽(간장↔막야)이면 발동. 쌍검 카드는 항상 발동, 쌍검 카드를 쓴 직후 다음 간장·막야 카드는 어느 쪽이든 발동 |
| 쌍검 | 간장·막야 둘 다로 취급하는 카드. 처음 쓰면 둘 다 소환. 그 카드에는 간장 효과(피해)와 막야 효과(방어도)가 함께 붙음. 쓴 뒤 현재 검은 간장 |
| 【명령】 | 오니마루가 그 자리에서 현재 종류로 자동 공격 1회 [확정]. 현재 검 보너스 포함, 25% 무작위는 적용 안 함 |
| 【발도】 | 솔라시의 빛을 전부 소모하는 공격. 이 카드의 피해는 방어도를 무시 |
| 정화 | 상태이상·저주 카드 소멸, 또는 내 디버프(`PowerType.Debuff`) 감소·제거 |
| 망령 상흔 / 빛 | 스코프눙 / 솔라시 전용 수치(새 파워 2개). 스코프눙 디버프는 2026-10에 "상처" → **망령 상흔**(영어 Spectral Scar)으로 이름을 바꿨고, 체력 바에 다음 턴 손실분이 보라색으로 표시된다 |

## 5. 마검 강화 이벤트 (휴식처 "마검 강화")

### 5.0 현재 구현 — 강화 화면 (2026-10-09 코드 기준)
- 휴식처 선택지 "마검 강화"(`RestSite/SwordForgeRestSiteOption.cs`, 아이콘 `ui/rest_option_forge.png`). 강화할 수 있는 검(5단계 미만)이 있어야 켜진다.
- 카드 선택 화면 대신 **이벤트식 페이지**(`RestSite/EventChoiceScreen.cs`, 커밋 a9eb291)로 진행한다. "돌아가기"는 한 단계 뒤로, 첫 페이지에서는 휴식처로 돌아간다(휴식처는 그대로 열려 있음).
  1. **만검총 페이지**: 제목 "강화할 마검을 고르세요", 본문 `MAGICSWORDSMAN_FORGE_UI.TOMB_TEXT`, 만검총 그림. 버튼 = "{검} — {단계}단계 {단계 이름}" + 그 검의 현재 검 효과 한 줄. 간장·막야는 한 버튼(대표 간장).
  2. **검 페이지**: 그 검의 도입 문구(`SWORD_LORE.<검>.FORGE_INTRO`) + 현재 단계 이름, 버튼은 안전 강화(+1, 확정) / 도박 강화 +2 / 도박 강화 +3 — 각 버튼에 검별 문구(`FORGE_SAFE`, `FORGE_GAMBLE`, `FORGE_GAMBLE3`)와 **실제 확률**(유물 보정 포함)을 표시. 5단계를 넘는 도박은 보이지 않는다.
  3. **결과 페이지**: 검별 성공·실패·박살 문구 + 결과 줄(`FORGE_STORY_RESULT_TOKEN.*`). 그람이 5단계에 처음 닿으면 니벨룽 문구가 붙는다.
- 확률(`RestSite/SwordForge.cs`, [임시]): 도박 +2 = 성공 65 / 실패 32 / 박살 3, 도박 +3 = 40 / 52 / 8. 레긴의 모루는 성공 +10%p(실패에서 뺌), 흑칠 칼집은 다음 박살 1번을 실패로 바꾼다.
- 실패 = 그 검의 저주 1장 또는 단계 −1(50:50, 0단계면 저주만, 저주 카드가 없으면 "아무 일도 없음"). 박살 = 검을 잃고 카드는 만검총에 보관, 그람은 대신 0단계로.
- 결과 문구(현재): 성공 "{검} — {단계 이름}. ({이전} → {새}단계)" / 단계 하락 "{검}의 날이 무뎌졌다. (…)" / 저주 "저주를 얻었다: {저주}." / 박살 "검의 카드는 만검총에 잠든다. 다시 찾으면 돌아온다." / 그람 박살 "{검} — {단계 이름}. ({이전} → 0단계)".

### 5.1 공통 흐름·문구 (설계 당시)
- 검 고르기 → 도입 2~3줄 → 버튼 → 결과.
- 버튼:
  - **[안전 강화]** "{안전 문구} — 단계 +1 (확정)"
  - **[도박 · 2단계]** "{도박 문구} — 성공 65% +2 / 실패 32% / 박살 3%" (현재 3단계 이하일 때만) [임시]
  - **[도박 · 3단계]** "모든 것을 건다. — 성공 40% +3 / 실패 52% / 박살 8%" (현재 2단계 이하일 때만) [임시]
  - **[그만둔다]** "아직은 때가 아니다."
  - 최대치를 넘기는 도박은 회색 비활성: "검이 더 받아들이지 못한다."
- 결과 공통 끝 문구:
  - 성공: "{검} — {새 단계 이름}." (예: "그람 — 모루를 쪼갠 그람.")
  - 실패(저주): "저주를 얻었다: {저주 이름}." (조사 문제로 현재 문구로 바꿈) / 실패(단계 하락): "{검}의 날이 무뎌졌다. ({이전} → {새} 단계)"
  - 박살: "검의 카드는 만검총에 잠든다. 다시 찾으면 돌아온다." (그람 제외)

## 6. 마검 획득 이벤트

### 6.0 런 시작 — 무작위 첫 검 + 그 곁의 검 고르기 (현재 구현)
- **첫 검 (2026-10-09)**: 런을 만들 때(`RunManager.FinalizeStartingRelics` → `Mangeomchong.AfterObtained`) 10자루(간장·막야는 한 쌍) 중 무작위 1자루를 받는다. 시드 고정: 플레이어 자신의 시드(런 시드 + 플레이어 자리)로 만든 이름 붙은 Rng(`magicswordsman_starting_sword`) — 같은 시드면 같은 검, 멀티플레이에서는 플레이어마다 따로 굴리고 모든 클라이언트에서 같다. 게임 Rng는 건드리지 않는다. 그 검의 시작 카드 2장(`StarterCards`, 획득 때와 같은 카드)이 바로 덱에 들어가고, 간장·막야면 최대 체력 −6(획득 대가)도 그때 적용된다. 저장은 다른 획득과 같은 `OwnedSwordIds`·`EverOwnedIds` + 런 카운터 `start.first_sword`.
- 시작 덱: 타격 ×4, 수비 ×4, 검 바꾸기 (9장) + 첫 검 시작 카드 2장 = 11장 → 아래 고르기 뒤 13장.
- 런 시작(막 번호 0)에 같은 `TombResonanceEvent`가 START 문구로 열린다: "길을 나서기 전, 등 뒤의 만검총이 낮게 울린다. 이번 길에 가장 먼저 깨어난 검 — {첫 검}. 그 곁에 설 검을 하나 더 데려갈 수 있다." 열릴 때 첫 검의 획득 팝업(머리글 "이번 길에 만검총에서 가장 먼저 깨어난 마검")이 뜬다. 후보는 첫 검을 뺀 무작위 3자루 중 1자루, [지나친다] 없음(사용자 결정 2026-10-04). 니오우(Neow)로 시작한 런에서는 니오우가 끝난 뒤 열린다.
- 검을 처음 얻으면 획득 팝업(`Visuals/SwordAcquiredPopup.cs`)이 뜬다: 검 그림·이름·한 줄 소개·기원·"현재 검일 때" 효과(`SWORD_LORE.*.EFFECT`)·대가·카드 성향(`STYLE`)·함께 받는 카드.
- 만검총이 가득 차면 "풀어 줄 검" 페이지(RELEASE)가 열린다. 풀려난 검의 카드는 만검총에 보관되고 강화 단계는 0이 된다. 그람도 풀어 줄 수 있다(커밋 a8be686).

### 6.1 1막 보스 후 확정 이벤트 — "만검총의 울림" `TombResonanceEvent` [확정 구조: 무작위 후보 3자루 중 1]
> 보스가 쓰러지자 등 뒤의 만검총이 울린다.
> 문틈으로 낯선 칼날 세 자루의 빛이 새어 나온다.

### 10.5 플레이 테스트에서 먼저 볼 조합
1. 칼라드볼그 + 공용 다단(연속 베기·세 번 찌르기): 타격마다 3명 → 다수 적 전투가 너무 쉬우면 "추가 대상 피해 75%".
2. 다인슬레이프 + 0비용 카드(칼집에서 뽑다·찌르기·바꿔 쥐기): 턴당 12장 상한이 실제로 닿는지.
3. 쿠사나기 계승 솔라시(0.4 #6): 전투당 2빛이 과한지.
4. 오니마루 스스로 움직이는 칼 + 난무 5단계 + 엘리트: (2+1+1)×5×2 = 40/턴.
5. 그람 5단계 + 레긴의 재단조 + 두 조각 + 발뭉·노퉁.
6. 티르빙 + 쿠사나기 + 난쟁이의 저주: 악행 3장 소멸 → 티르빙 +9, 힘 +3.

### 12.3 총평
- **B**가 수치·구조·구현 정확도에서 가장 안정적이라 표·공식·이벤트 구조의 뼈대가 되었다. 약점은 재미(검마다 빌드 축이 하나)와 그람 카드 성장.
- **A**는 원전 연결이 가장 촘촘하다(단계 이름, 티르빙 악행 순서, 스코프눙 돌·롤랑의 바위, 검총의 네 자루). 카드 이름·원전 줄·유물 대부분이 A에서 왔다. 솔라시 충전 증가는 [확정] 위반이라 버렸다.
- **C**는 시너지 설계가 가장 좋다(공용 = 운반체, 턴 종료 현재 검 경쟁, 몸 밑에 숨긴 검, 삼종신기, 악행 저주 소멸 보상, 레테의 검). 그 아이디어를 카드 단위로 옮겨 붙였다. 솔라시 충전 증가·오니마루 첫 카드 소환·Boss 희귀도는 위반·오류라 버렸다.

### 12.4 사용자 확인이 필요한 해석 (★, 0.4 참고)
1. 솔라시 충전량을 단계와 무관하게 1로 고정하고 단계는 빛당 피해(K)를 올림.
2. 쿠사나기가 솔라시를 계승한 채 턴을 마치면 솔라시로 취급(빛 1 충전, 소멸 없음).
3. 쿠사나기 전투 종료 HP 상실은 "보유 중"(결정 기록 문구) — 현 코드 주석("소환된 전투만")을 고쳐야 함.
4. 티르빙 악행 저주는 Eternal(제거 불가) + 소멸 시 티르빙 +3.
5. 다인슬레이프 턴당 12장 엔진 상한.
6. 다인슬레이프 첫 소환 때 만검총 방어도 3은 받음(코드 순서).
