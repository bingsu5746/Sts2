# 마검사 데모 콘텐츠 — 최종 통합안 (구현용)

> **기준 문서**: `docs/magic-swordsman-spec.md`(2026-10-02). **[확정]·[임시] 항목은 하나도 바꾸지 않았다.** 이 문서의 이름·수치는 전부 사양 8절 "아직 비어 있는 것"을 채우는 **[Claude] 제안값**이다(사용자 확인 전까지 바꿀 수 있음).
> **원전**: `magic-sword-research.docx`(텍스트판 `s.txt`)에 있는 문장만 썼다. 「 」 안이 근거 문장이다. 보고서에 없는 역사·신화 사실은 넣지 않았다. 게임 메커니즘은 원전 문구를 모티프로 삼은 창작이다.
> **수치 기준**: 디컴파일한 실제 게임 카드(`MegaCrit.Sts2.Core.Models.Cards/*.cs`) 값. 10절에 대조표가 있다.
> **통합 출처**: 설계안 A(원전 중심), B(밸런스 중심), C(시너지 중심)를 섹션마다 평가해 가장 좋은 판을 고르고 다른 안의 좋은 아이디어를 붙였다. 각 섹션 끝 `출처`에 어느 안에서 왔는지 적었다. 점수는 12절.
> **코드 기준**: 검 ID는 `MagicSwordsmanCode/Swords/SwordId.cs`(Gram, Ganjiang, Moye, Kusanagi, Tyrfing, Dainsleif, Durandal, Skofnung, Onimaru, ClaiomhSolais, Caladbolg). 카드 기반 클래스는 `Cards/MagicSwordCard.cs`(`WithDamagePerLevel`, `WithBlockPerLevel`, `WithLevelVar`로 단계 반영), 저주는 `Curses/SwordCurseCard.cs`, 검 규칙은 `Swords/Behaviors/*Behavior.cs`.

## 0. 공통 규칙

### 0.1 표기
| 표기 | 뜻 |
|---|---|
| **L** | 그 마검의 강화 단계(0~5). 카드 설명에는 현재 단계가 반영된 숫자만 보인다(`WithLevelVar` 등) |
| `+1/L` | 단계마다 +1 (0단계 값 + L) |
| `+⌊L/2⌋` | 2단계·4단계에서 1씩 (0,0,1,1,2,2) |
| `3단계부터 X` | 문턱형. 3단계 이상에서 X로 바뀜 |
| 공용 카드 `6 (9)` | 기본 6, 휴식처 일반 강화 후 9 |
| 대상 | 적1 = `TargetType.AnyEnemy` / 전체 = `AllEnemies` / 무작위 = `RandomEnemy` / 자신 = `Self` (게임 열거형에서 확인) |
| 희귀도 | `CardRarity.Basic`(검을 얻을 때 지급, 보상·상점에 안 나옴) / `Common` / `Uncommon` / `Rare` |

### 0.2 단계당 상승 공식 (마검 카드 공통)
| 카드 성격 | 단계당 | 5단계 누적 | 원본 강화 1회와 비교 |
|---|---|---|---|
| 비용 0~1 단일 공격 | 피해 +1 | +5 | StrikeIronclad +3, Headbutt +3 |
| 비용 2 공격 | 피해 +2 | +10 | Predator +5 |
| 비용 3 공격 | 피해 +3 | +15 | Bludgeon +10 |
| 여러 번 때리기 | 타격당 +⌊L/2⌋ | 타격당 +2 | TwinStrike 타격당 +2 |
| 비용 0~1 방어도 | +1 | +5 | DefendIronclad +3 |
| 비용 2 방어도 | +2 | +10 | BloodWall +4 |
| 파워·특수 수치 | +⌊L/2⌋ 또는 문턱형(비용 감소 등) | — | Inflame +1 |
| **그람 카드(예외)** | 위 값의 절반: 비용 0~1 공격 +⌊L/2⌋, 비용 2 공격 +1/L, 다단은 4단계부터 타격당 +1 | — | 현재 검 효과 +L이 이미 모든 공격을 올리므로 이중 상승을 줄임 |

- 5단계 마검 카드 1장 ≈ 원본 강화 1.5~2회. 휴식처 1회 = 그 검 카드 3~5장 동시 상승 + 현재 검 효과 상승 → 일반 강화 1회보다 약간 높게(도박·박살 위험과 휴식 포기의 대가).
- 그람 카드도 "그 검의 카드 전부가 조금씩 강해짐"[확정 §4]을 지키도록 절반이라도 반드시 오른다(설계안 B는 그람 카드를 거의 올리지 않아 이 조항과 어긋날 여지가 있었음).

### 0.3 용어·키워드
| 용어 | 뜻 |
|---|---|
| 소환 | 그 검의 카드를 전투에서 처음 쓸 때 만검총에서 나옴(검마다 전투당 1회). 전투 첫 소환에만 만검총 효과(방어도 3 + 카드 1장) [확정] |
| 나온 검 수 | 이번 전투에 주변에 떠 있는 검 수 = `SwordCombatState.Present` 개수(소환된 검 + 스스로 나온 오니마루). 간장·막야는 각각 1. 봉인된 쿠사나기는 빠짐 |
| 전환 | 현재 검이 다른 검으로 바뀌는 순간(없음 → 검 포함). 같은 검 카드를 연달아 쓰는 것은 전환이 아님 |
| 【연속】 | 이 카드를 쓰기 직전 현재 검이 이미 이 카드의 검이면 발동 |
| 【짝】 | 간장·막야 전용. 쓰기 직전 현재 검이 반대쪽(간장↔막야)이면 발동. 쌍검 카드는 항상 발동, 쌍검 카드를 쓴 직후 다음 간장·막야 카드는 어느 쪽이든 발동 |
| 쌍검 | 간장·막야 둘 다로 취급하는 카드. 처음 쓰면 둘 다 소환. 그 카드에는 간장 효과(피해)와 막야 효과(방어도)가 함께 붙음. 쓴 뒤 현재 검은 간장 |
| 【명령】 | 오니마루가 그 자리에서 현재 종류로 자동 공격 1회 [확정]. 현재 검 보너스 포함, 25% 무작위는 적용 안 함 |
| 【발도】 | 솔라시의 빛을 전부 소모하는 공격. 이 카드의 피해는 방어도를 무시 |
| 정화 | 상태이상·저주 카드 소멸, 또는 내 디버프(`PowerType.Debuff`) 감소·제거 |
| 상처 / 빛 | 스코프눙 / 솔라시 전용 수치(새 파워 2개) |

출처: 카드 뼈대는 A(원전 문구·이름)와 B(수치·실효 점검)를 기본으로, C의 시너지 카드를 붙였다. 검별: 그람 = A·C 카드 + B 레긴의 재단조(드로우 보정) + A 발뭉·노퉁에 C 성난 자의 "겹치지 않음" 규칙 / 간장·막야 = A·B·C 혼합, 암수 한 쌍은 C / 쿠사나기 = A 정화 축 + C 곡옥·거울·삼종신기 / 티르빙 = A·B 수치 + C 저주 연계(드발린과 두린=C 목숨값, 난쟁이의 저주) / 다인슬레이프 = C 카드 + B 빗나가지 않는 칼 + A 반복 방지 원칙 / 뒤랑달 = A 카드 + C 몸 밑에 숨긴 검·누적 강화 + B 상한 수치 / 스코프눙 = B 카드 + A 금기를 지키다·C 흐롤프 크라키의 검 / 오니마루 = B 구조(자체 피해 없음, 표 하나) + A 이름 / 솔라시 = C 카드 + B K 방식·마그 투이레드 대가 / 칼라드볼그 = A·B·C 혼합, 레테의 검은 C.

### 12.3 총평
- **B**가 수치·구조·구현 정확도에서 가장 안정적이라 표·공식·이벤트 구조의 뼈대가 되었다. 약점은 재미(검마다 빌드 축이 하나)와 그람 카드 성장.
- **A**는 원전 연결이 가장 촘촘하다(단계 이름, 티르빙 악행 순서, 스코프눙 돌·롤랑의 바위, 검총의 네 자루). 카드 이름·원전 줄·유물 대부분이 A에서 왔다. 솔라시 충전 증가는 [확정] 위반이라 버렸다.
- **C**는 시너지 설계가 가장 좋다(공용 = 운반체, 턴 종료 현재 검 경쟁, 몸 밑에 숨긴 검, 삼종신기, 악행 저주 소멸 보상, 레테의 검). 그 아이디어를 카드 단위로 옮겨 붙였다. 솔라시 충전 증가·오니마루 첫 카드 소환·Boss 희귀도는 위반·오류라 버렸다.

### 12.4 사용자 확인이 필요한 해석 (★, 0.4 참고)
1. 솔라시 충전량을 단계와 무관하게 1로 고정하고 단계는 빛당 피해(K)를 올림.
2. 쿠사나기가 솔라시를 계승한 채 턴을 마치면 솔라시로 취급(빛 1 충전, 소멸 없음).
3. 쿠사나기 전투 종료 HP 상실은 "보유 중"(결정 기록 문구) — 현 코드 주석("소환된 전투만")을 고쳐야 함.
4. 티르빙 악행 저주는 Eternal(제거 불가) + 소멸 시 티르빙 +3.
5. 다인슬레이프 턴당 12장 엔진 상한.
6. 다인슬레이프 첫 소환 때 만검총 방어도 3은 받음(코드 순서).
