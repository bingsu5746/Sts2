# 화산파 14장 (초안 — 사용자 검토 대기)

`wuxia-character-spec.md`의 문파 카드 공통 틀(공격·방어 12장: 입문3/숙련4/상승3/절학2 + 심법 2장: 즉시 회복=숙련, 매 턴 회복=상승)에 맞춘 첫 제안. 근거는 `hwasan-research.docx`. 수치(피해·방어도·에너지·내공)는 **밸런스 전 임시값**.

## 화산 정체성
- **연타(쾌검)**: 리서치 "화산은 속도로 이긴다", "1회 타격이 아니라 다단 히트로 설계해야 원전에 맞는다". 무당(속도 1~3, 파괴력 8)과 정반대 축.
- **만개(滿開)**: 리서치 "타격이 누적될수록 매화가 피어나고, 만개하면 추가 효과가 터지는 식". 단, `sect-mechanics-sketch.md`에 "화산 카드에 도트/스택 넣지 말 것(당가와 구분)"이 있어서 **이번 턴에 낸 공격 카드 수만 센다** (턴이 끝나면 초기화, 적에게 쌓이는 스택 없음).
  - 만개 = 이번 턴 공격 카드를 3장 이상 냈으면 (3장 기준은 임시)
- 내력 색은 붉은빛, 아트는 "화려함·속도·흩날림" (리서치 아트 디렉션).

## 등급 어긋남
리서치에서 ★인 무공은 육합검법·낙화검·칠매검 3개뿐이고, 육합검법은 시작덱 카드라 입문 칸이 1개 모자란다. 그래서 오행매화보(★★)를 입문으로 내리고, 숙련 방어 카드로 태을미리보(★★★)를 내렸다.
