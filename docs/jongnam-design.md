# 종남파 14장 (초안 — 사용자 검토 대기)

`wuxia-character-spec.md`의 문파 카드 공통 틀(공격·방어 12장: 입문3/숙련4/상승3/절학2 + 심법 2장: 즉시 회복=숙련, 매 턴 회복=상승)에 맞춘 첫 제안. 근거는 `jongnam-research.docx`. 수치는 **밸런스 전 임시값**.

## 종남 정체성
- **버티기**: 리서치 "방어 수치가 높아야 종남이다. 카운터가 아니라 버티기가 승리 조건이다." → 무당(반격)과 구분. 방어도가 높고, 방어도를 다음 턴까지 남기는 카드가 있다.
- **대기만성(大器晩成)**: 리서치 "누적 턴 수에 비례해 위력이 오르는 구조로 옮긴다." → **전투 3번째 턴부터** 켜지는 조건 (3턴 기준은 임시). 화산의 "만개"와 같은 방식의 단순 조건.
  - 무당 태극혜검(카드를 손에 오래 들고 있을수록 강해짐)과 다름: 종남은 카드와 상관없이 **전투가 길어질수록** 강해짐.
- 화산과 반대: 화산은 빠른 연타, 종남은 묵직한 단발. 리서치 "화려한 다색 금지 — 화산과 헷갈리면 안 된다".

### 기존 스케치와 달라진 점
`sect-mechanics-sketch.md`에는 종남 메커니즘을 `예비(豫備)`(이번 턴 예약 → 다음 턴 증폭 재발동)로 적어 뒀었다. 리서치의 "대기만성" 제안이 더 단순해서 이 초안은 대기만성을 쓴다.

### 쓰지 않은 리서치 제안
- 음공 결손 페널티 ("음 속성 무공을 아예 보유할 수 없게") — 우리 게임에 음/양 속성 구분이 없어서 제외.

## 등급 어긋남
리서치 ★는 천하삼십육검·장괘장권구식 2개뿐이라 북두천강보(★★)를 입문으로 내렸다. 천하삼십육검은 리서치에서 "이십사수매화검법, 태극검·태극혜검과 비슷한 비중"이라 하지만 등급표상 ★(1단계 근간 무공)이라 입문에 둔다.
