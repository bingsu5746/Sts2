# 새 캐릭터(가칭: 영혼 계약자) — 설계 진행 기록

> 사용자와 브레인스토밍하며 확정한 내용만 적는다. 확정 사양서는 설계가 끝난 뒤 따로 쓴다.
> 표기: **[확정]** 사용자가 정함 / **[제안]** Claude 제안, 아직 확정 아님

## 1. 컨셉
- [확정] 웹툰 「사신소년」의 **시스템만** 가져온다. 인물·고유명사는 새로 만든다.
- [확정] 한 런에 위인 1명. 한 번 고르면 바꿀 수 없다.
- [확정] 위인의 코어는 **런 시작 고유 이벤트**로 얻는다. 티켓(수명 거래)은 쓰지 않는다.
- [확정] 성장형: 빙의 → 동기화 → 집중 → 강림. 3막에서 가장 강해진다.
- [확정] 단계 상승은 혼합 방식: 막 진행이 다음 단계 상한을 열고, 실제 진입은 숙련 조건을 채워야 한다(숫자 미정).

## 2. 런 시작 이벤트 — 「황천 영사실」 [확정]
- 10개 아이디어 비교(에이전트 10명 1라운드 제안 + 2라운드 교차 평가) 끝에 영사실 연출 + 업경대식 공개를 합친 안으로 결정.
- 시안 페이지: https://claude.ai/artifact/Db6PAQQQxcKC26iaKRBNBm (관우·잔 다르크·이순신 예시)

### 흐름
1. 암전: "당신은 1초 뒤에 죽는다."
2. 시드로 고른 **장면**(배경·상황) 1개 위에서 컷 3개(시선 → 행동 → 유언)를 고른다.
3. 객석에 시드로 뽑힌 위인 3명의 실루엣과 한 키워드. 고를 때마다 맞는 실루엣이 빛나며 앞으로, 나머지는 흐려진다.
4. 강하: 위인이 스크린 속으로 걸어 들어오고 이름 컷인.
5. 공개: 화면 분할 — 왼쪽은 내가 고른 3컷, 오른쪽은 그 위인의 실제 일화/마지막 행적.
6. 계약.

### 규칙
- [확정] 컷마다 고른 선택지가 해당 위인에게 공명(동그라미) +1. **가장 많이 받은 위인**이 온다. 낮은 위인을 억지로 고르는 경로는 없다.
- [제안] 1:1:1 동점이면 마지막 컷(유언)에서 고른 위인.
- [확정] 계약 유형: 공명 3/3 → **공명 계약**(안정, 동기화 쉬움). 2/3 이하 → **한 계약**(더 강한 시작 + 한 게이지·영혼 지배 위험, 다른 위인에게 준 공명이 "섞인 결"로 남음).
- [확정] 장면은 위인의 가치관이나 유명한 행동 중 하나를 고르게 만드는 상황이다(예: 포위된 성의 마지막 밤).
- [확정] 장면마다 배경을 매우 다양하게 만든다.
- [확정] 장면을 **매우 많이** 만들어 런마다 겹치지 않게 한다.

### 콘텐츠 구조
- 위인 데이터: 가치관 태그 2~3개, 유언 대사, 실제 일화/마지막 행적(사료로 확인한 범위만), 한 키워드.
- 장면 데이터: 배경, 상황 묘사, 그리고 **가치관 태그별** 컷 3개 문장.
- 선택지 조립: 컷마다 뽑힌 위인 3명 각각의 가치관 태그 문장을 1개씩 넣는다. 태그가 겹치면 한쪽은 2순위 태그.
- [제안] 문장은 위인별이 아니라 태그 단위로 쓴다(위인 20 × 장면 8 × 3컷 = 480줄 → 태그 10 × 장면 8 × 3컷 = 240줄). 위인 개성은 유언 대사와 공개 화면에 몰아넣는다.
- [제안] 장면이 모든 태그를 다 지원할 필요는 없다. 시드로 장면을 고를 때 이번 3명의 태그를 모두 지원하는 장면만 후보로 삼는다.
- [확정] 위인별 가치관·행동·유언 정리 문서는 나중에 사용자와 함께 만든다.

### 런 전체 연결
- 1·2막 보스 뒤: 그 위인의 마지막 순간을 한 컷씩 더 상영(동기화 연출).
- 3막 강림: 내 유언과 위인의 유언을 나란히.

## 3. 위인 로스터
- [확정] 첫 출시는 **6명**. 이후 업데이트로 계속 추가한다. (6명 중 3명 출연 = 조합 20가지)

- [확정] 첫 6명: **관우, 잔 다르크, 레오니다스, 칭기즈 칸, 이순신, 나폴레옹**

## 4. 카드풀
- [확정] 공용 카드 + 위인 전용 카드. 보상·상점에는 공용 + 계약한 위인 카드만 나온다(마검사 만검총 방식).
- [확정] 위인 카드 일부는 단계가 올라야 보상에 나온다(빙의: 기본 / 동기화: 기억 / 집중: 기술 / 강림: 궁극).
- [확정] 공용 카드는 최대한 적게, 위인별 카드는 최대한 많이.
- 참고: 카드풀 장 수에 엔진 상한은 확인되지 않았다. 바닐라 캐릭터 풀은 87~88장(`docs/sts2-engine-analysis.md:21`)이고, 마검사는 한 풀에 그보다 훨씬 많은 카드를 넣어 동작 중이다.

## 5. 아직 정할 것
- 단계별 숙련 조건, 위인별 카드풀 구조
- 공명/한 계약의 구체적 수치
- 캐릭터 이름, HP, 시작 덱, 시작 유물
