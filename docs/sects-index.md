## 각 문파 한 줄 요약 (리서치 문서 서두 기준)

- **소림사**: "천하공부출소림" — 무술의 종주. 사공 계열(환술·색공·최면술)과 검법을 빼면 대부분의 무공이 다 존재한다는 설정이 보편적. 소림칠십이예로 통칭. 권법·봉법(둔기 타격) 중심.
- **화산파**: 도가 검문. 매화(梅花) 상징, 검의는 쾌(快)·변(變)·환(幻). 내력은 붉은빛. 무당의 소나무와 대비되는 이미지.
- **종남파**: 중검(重劍)의 도가 문파. 화산파와 라이벌이지만 취급은 늘 "몰락한 명문" 포지션 — 이 서사적 낙차 자체가 종남의 자산. 대표 무공 천하삼십육검.
- **사천당가**: 독(毒)과 암기(暗器)의 가문. 독심(毒心)이라 불리는 냉혹한 이미지가 선역/악역 가리지 않고 따라붙음. 독=약이라는 연결로 의술에도 정통.
- **제갈세가**: 무력보다 지략 중심 가문. 진법·기관진식·용인술·전술에 도통, 무림맹 군사(참모) 역할로 자주 등장.
- **남궁세가**: 오대세가의 필두로 자주 배치되는 중검 가문. 창궁(蒼穹, 무한한 변화·드넓음)과 제왕(帝王, 압도·군림) 두 축이 가문 정체성.
- **하북팽가**: 도(刀)의 가문. 패도(霸道)·강맹(剛猛) 이미지의 대명사 — 남궁이 검, 제갈이 머리라면 팽가는 정면 파괴. 이미지가 단순해 조연 소비가 잦은 편이라 뒤집을 거리가 필요.
- **천마신교**: 정파 전체와 대립하는 구조적 안타고니스트 세력. 마공은 정파보다 성장이 빠른 대신 주화입마·수명단축 등 대가가 따름. 흡성/혈공 등 금기 수법.
- **북해빙궁**: 구파일방·오대세가·마교 어디에도 속하지 않는 제4의 세외세력. 극음의 한빙지기를 다루는 술법가형 전투 방식.

각 문서는 무당파 리서치와 동일한 형식(개요/철학/내공심법 등급표/무공 계보/수치화 제안/시각 묘사/아트 디렉션)을 따른다. 실제 카드 설계에 들어갈 때 해당 문서를 열어서 확인할 것.
