# 무명 — 그림 자리 목록 (디자인 교체용)

같은 경로·이름·크기로 파일을 덮어쓰면 코드 수정 없이 게임에 반영된다(`dotnet publish` 또는 pck 다시 만들기).
지금 들어 있는 그림은 모두 코드로 만든 임시 그림이다(`tools/gen_event_art.py`, `tools/gen_character.py`).
그림 안에 글자는 넣지 않는다(한/영 두 언어로 나오기 때문).

## 1. 이벤트 배경 — `Mumyeong/Mumyeong/images/events/`
- 크기: **1000×760 PNG** (가로:세로 25:19). 게임 이벤트 그림 칸의 정확한 크기는 확인하지 못했다.
  같은 저장소 엔시페르의 전설 이벤트가 1000×760 그림을 쓰고 있어 같은 크기로 맞췄다. 게임에서 잘리거나 늘어나면 알려 주세요.
- 파일이 없으면 영사실 그림(`theater_hall.png`)으로, 그것도 없으면 게임 기본 그림으로 대신 나온다.

## 2. 캐릭터 — `Mumyeong/Mumyeong/images/character/`
| 파일 | 크기 | 담을 것 |
|---|---|---|
| `reaper.png` | 560×860, 투명 배경, 발이 아래 가운데 | 서 있는 저승사자(검은 코트, 중절모, 연기로 가린 얼굴), 오른쪽(적 쪽)을 향함 |
| `reaper_rest.png` | 420×480, 투명 배경 | 바위에 앉은 저승사자, 오른쪽(모닥불 쪽)을 향함 |
| `spirit_<위인>.png` | 680×1010, 투명 배경 | 서 있는 영혼(창백한 푸른빛, 아래로 갈수록 안개로 사라짐). 머리는 위에서 약 1/3 지점 |
| `spirit_<위인>_rest.png` | 680×1010, 투명 배경 | 앉은 영혼(같은 크기의 캔버스 안, 아래쪽 절반에 앉은 모습) |
| `char_select_bg.png` | 1920×1080 | 선택 화면 배경. 오른쪽은 비워 둔다(저승사자와 영혼이 올라간다) |

`<위인>` = guanyu, joan, leonidas, genghis, yisunsin, napoleon.
말풍선 위치는 `MumyeongCode/Dialogue/SpiritTalk.cs`의 기준점(얼굴 위치)을 따른다. 얼굴 위치가 크게 달라지면 그 값도 고친다.
